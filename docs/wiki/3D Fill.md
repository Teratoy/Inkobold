# 3D Fill

**id** `fill3d` · **key** `F`

Flood then shade. Modes: `classic`, `addiction`, `wavy`, `drift`, `depression`. Uses [[View|Sun]].

With [[View|Wrap Moves]] on, flood crosses opposite edges and emboss (blur / normals) is toroidal — squares and rectangles that straddle a tile seam shade as one seamless form.
