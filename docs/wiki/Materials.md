# Materials

Sun-aware relief materials. Light direction follows the canvas [[View|Sun]] when Use Sun Light is on.

| Effect | Notes |
|--------|-------|
| Metal Relief | Presets: Copper, Silver, Gold, Brass, Bronze |
| Milk | Creamy fluid relief + bubbles / voids / spoil |

When sun is deactivated: Metal `(-0.45,-0.55,0.70)`, Milk `(-0.40,-0.50,0.76)`.
