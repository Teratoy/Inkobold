# Lay

**id** `lay` · **key** `K`

Lays pattern-library elements along a drawn path. Pick a pattern from [[Libraries]], then drag a path like [[Line]] / [[Curve]].

## Shape modes

- **Line** — straight path; **Shift** snaps to 45°
- **Freehand** — Bézier fit to the drag (same as Curve freehand); **Alt** flips bulge
- **Arc** — circular arc; **Degrees** sets the central angle; **Alt** flips side
- **Circle** — press center, drag radius; **Alt** treats the drag as a diameter

## Settings

| Setting | Role |
|---------|------|
| **Element Size** | Longest side of each stamped pattern element (pixels) |
| **Distance** | Spacing between element centers along the path |
| **Pattern** | Image from Libraries → Patterns (colors preserved; not tinted) |
| **Opacity** | Stamp strength |

Elements rotate to follow the path tangent.
